PUBLICATION · ACMSE 2026

iGenOrch

Intelligent Orchestration Framework for Multi-Model LLM Inference on Edge Platforms. iGenOrch connects runtime telemetry with a modified Linux scheduling layer to manage concurrent LLM workloads on constrained edge devices.

The work monitors request latency, queue size, token throughput, CPU, and memory usage, then adapts CPU affinity, process priority, concurrency, and batch size.

RELATED WORK · RESEARCH CONTEXT

Where my work fits

Prior work on efficient edge LLM inference has explored model compression, quantization, optimized runtimes, speculative decoding, DVFS, model partitioning, SLO-aware serving, and multi-model resource sharing. Other studies use runtime state or contextual learning for model selection and serving decisions. My current work targets a complementary layer: a closed-loop control mechanism that observes live model and system telemetry and translates it into operating-system resource-management actions for heterogeneous LLM processes executing concurrently, without modifying the underlying models or replacing the kernel scheduler.
