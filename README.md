# Maisha Rahman Chowdhury — Portfolio

A responsive, GitHub Pages-ready personal portfolio for My works.

## Files

- `index.html` — portfolio content
- `style.css` — styling and responsive layout
- `script.js` — smooth scrolling and reveal animations
- `assets/` — resume, CV, and research PDFs

## Deploy to GitHub Pages

1. Create a public repository named `maisharchy.github.io`.
2. Copy everything in this folder into the repository.
3. Commit and push:
   ```bash
   git add .
   git commit -m "Create portfolio"
   git push
   ```
4. In GitHub, open **Settings → Pages**.
5. Select **Deploy from a branch**, choose `main`, and choose `/ (root)`.
6. My site will be available at `https://maisharchy.github.io`.
